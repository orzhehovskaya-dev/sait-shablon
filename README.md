# Шаблон сайту для послуг з онлайн-записом і оплатою

Готовий сайт: головна, три сторінки послуг, запис на вільний час з оплатою WayForPay, синхронізація з Apple Calendar (iCloud), Zoom, листи клієнтам, сповіщення в Telegram, адмінпанель.

Це шаблон із гайду «Сайт для послуг». Покроково, з телефона: дивись уроки гайду.

## З чого почати

1. Натисни зелену кнопку **Use this template → Create a new repository** - у тебе з'явиться власна копія.
2. Заміни тексти й контакти у файлі `content/site.ts` (усі «Твоє Ім'я», «my.brand», «your_instagram», «hello@example.com»).
3. Заміни послуги, ціни й тривалість у `content/services.ts`.
4. Заміни фото в `public/images/` (ті самі назви файлів) і `public/og.jpg` (картинка для прев'ю посилання, 1200×630).
5. Підключи сервіси за інструкцією [docs/SETUP.md](docs/SETUP.md).

- **Як усе влаштовано:** [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- **Адмінка:** `/admin` (вхід через Supabase, див. SETUP.md, крок 2).

## Важливо

- Секретні ключі - лише у Vercel → Settings → Environment Variables. Ніколи не вставляй їх у код, чат чи скриншоти.
- Не пиши на сайті домашню адресу, телефон і РНОКПП - достатньо назви ФОП і email.
- Правила перенесення/скасування в `content/site.ts → policies` - чернетка. Перевір їх: вони потрапляють у листи й оферту.
- Кейси та відгуки: додай їх у `cases.items` і `reviews.items` (приклад - у коментарях файлу). Поки списки порожні, ці блоки на сайті не показуються.
- Ціни в гривнях сайт рахує сам за курсом НБУ. `uahRate` - лише запасний курс.

Для розробників:

```bash
npm install
cp .env.example .env.local
npm run dev     # http://localhost:3000
npm test
```
